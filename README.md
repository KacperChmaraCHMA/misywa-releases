# MISYWA · Oficjalne wydania

Publiczny kanał wydań aplikacji **MISYWA** dla macOS i Windows. Kod źródłowy oraz testy pozostają w prywatnym repozytorium `KacperChmaraCHMA/misywa-desktop`.

## Aktualny status

**Kanał jest przygotowywany.** Nie opublikowano jeszcze oficjalnych instalatorów ani włączonej automatycznej instalacji aktualizacji. MISYWA 0.8.0 jest wydaniem deweloperskim.

Gdy dostępne będą oficjalne wydania, pojawią się w zakładce [Releases](https://github.com/KacperChmaraCHMA/misywa-releases/releases). Klient pocztowy sprawdza wyłącznie najnowsze stabilne wydanie z tego repozytorium.

## Zasady publikacji

- **Nigdy** nie przesyłamy tu wiadomości, załączników pocztowych, bazy SQLite, danych kont ani haseł.
- Publikację wersji stabilnej poprzedzają testy CI na macOS (Apple Silicon i Intel) oraz Windows.
- Oficjalne binaria wymagają podpisów kodu; macOS także notarizacji Apple.
- Instalator i metadane aktualizacji muszą przejść weryfikację integralności i pochodzenia.
- Do czasu wdrożenia zweryfikowanego aktualizatora MISYWA **nie podmienia automatycznie plików aplikacji**.

Kanał ten jest przeznaczony wyłącznie do publicznej dystrybucji. Nie służy do przyjmowania prywatnych danych użytkowników.
